# LANChat-java
Simple Chatting application write in java and use Terminal-based

LANChat-Java is a lightweight terminal-based chat application written in Java 17 for local networks. 
It is designed for environments where a graphical interface is unavailable or unnecessary, 
such as headless Linux servers and single-board computers.

Requirements

- Java 17 or newer
- Any OpenJDK-compatible distribution
- Windows or Linux
